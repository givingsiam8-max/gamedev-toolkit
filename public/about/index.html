About

A toolkit built for daily game development work

GameDev Toolkit puts 77 focused utilities in one workspace, so you can inspect a model, resize a texture, slice a sprite sheet, check a shader colour and format a JSON file without installing a dozen separate programs or uploading assets to random websites.

Why it exists

Small tasks interrupt real work: a texture is 2048×2049, a sprite sheet needs splitting, an FBX has to become a GLB, a GUID needs checking. Those tasks are usually spread across desktop apps, command-line one-offs and ad-supported converters. This project collects them behind one consistent interface with the same behaviour every time.

What is inside

3D and materials

Model viewer, converter, embedded texture extraction, mesh statistics and a lit PBR material preview.

Images, textures and sprites

Batch resize, convert and compress, channel packing, normal-map preview, seamless tiling, atlases and sprite slicing.

Audio and animation

WAV/MP3 conversion, trimming, gain and fades, waveform analysis, GIF decoding/encoding and frame previews.

Unity and developer tools

GUID and .meta helpers, layer bitmasks, quaternion and vector maths, JSON/XML/YAML, regex, diffs and hashing.

Local-first by design

Every tool runs in your browser. Images, models, audio and text are read from your disk into memory and processed there; there is no upload endpoint, no account and no server-side storage. Preferences such as favourites and recent tools live in your browser's localStorage and can be cleared from the Settings dialog.

How it is built

The interface is React and TypeScript on Vite. Each tool is an independent module that declares its own metadata and lazily loads its implementation, so heavy libraries — three.js, the MP3 encoder, YAML and GIF codecs — are only downloaded when you open the tool that needs them. The source code is public on GitHub.

Who it is for

Unity and Unreal developers, 2D and 3D artists, technical artists, designers and anyone who works with game assets regularly. The tools aim to be understandable without a manual: clear labels, visible results and honest messages when a browser cannot do something.
