Contact and support

GameDev Toolkit is a free, local-first project. Support happens in the public repository, so problems and fixes stay visible to everyone.

Report a bug

Something renders incorrectly, a file fails to load, or a tool produces the wrong output.

Open an issue

Security

Report vulnerabilities privately through GitHub's security advisory flow.

Private report

What to include

  • The tool name and what you expected to happen.
  • The file format and approximate size — not the confidential file itself.
  • Browser and operating system (for example Chrome 141 on Windows 11).
  • Any error message shown in the interface.

Please keep private files private

Issues are public. Do not attach client artwork, unreleased game assets or anything under NDA. Reproduce the problem with a synthetic sample instead; most bugs can be described with dimensions, formats and a screenshot of the error state.

No email or contact form

There is no contact form and no support email. A form would need a server that stores messages, which contradicts the project's local-only design. GitHub Issues is the support channel, and the repository also documents how the site is built and deployed.

Response expectations

This is a volunteer project with no service-level agreement. Bug reports and well-scoped feature requests are reviewed when time allows. Clear reproduction steps make a fix far more likely.
