Privacy Policy

Last updated: October 19, 2026

Short version: your files are processed in your browser and are never uploaded. There are no accounts, no tracking scripts and no advertising.

1. Files you open

When you drop an image, 3D model, audio file, archive or text file into a tool, it is read into the page's memory and processed by browser APIs. It is not transmitted to this site's operator or to any third party. Closing the tab or reloading the page discards the working data. Downloading a result creates a local file on your device.

2. Data stored on your device

The application stores a small set of preferences in your browser's local storage:

  • gdt.settings — theme, sidebar state and display preferences.
  • gdt.favorites and gdt.recent — tool IDs you starred or opened.
  • gdt.usage — a local count of how often each tool was opened.
  • gdt.tool.* — option values remembered by individual tools.

This data never leaves your browser and is not accessible to the site operator. You can erase it at any time with Settings → Reset all local data, or by clearing site data in your browser.

3. Cookies and analytics

The application does not set cookies and does not include analytics, advertising or session-recording scripts. If analytics were added in the future, this policy would be updated before activation and would describe the provider and data involved.

4. Hosting and server logs

The site is served by GitHub Pages, a service of GitHub, Inc. Like any web host, GitHub may process standard technical data (such as IP address, user agent and requested URL) to deliver content, prevent abuse and maintain security. That processing is governed by the GitHub Privacy Statement. The site operator does not receive or store those logs.

5. Network requests

Loading the application downloads its HTML, CSS, JavaScript chunks and image assets from the same GitHub Pages origin. Tools that use specialised libraries load additional code chunks from the same origin on demand. No tool sends your files to a remote service, and there are no third-party API calls at runtime.

6. Third-party software

The interface bundles open-source libraries such as React, three.js, fflate, js-yaml, gifenc, gifuct-js and an MP3 encoder. These run inside the page and do not include telemetry.

7. Children

The site is a general-purpose developer tool and is not directed at children under 13. It does not knowingly collect personal information from anyone, including children.

8. Changes to this policy

If the data practices change, this page will be updated and the date at the top will change. Material changes will be noted in the public repository.

9. Contact

Questions about this policy can be raised through the contact page or the public issue tracker. Please do not post private or confidential information in public issues.
